## 本地来源与核验结果

- `vendor/04_引脚功能信息/ACX720-V3管脚分配表2024_11_13.xlsx`，Sheet1：
  第 2 行时钟、第 4 行 LED0、第 27 行 S4、第 29/30 行 UART。
- `vendor/06_原理图&PCB/ACX720-V3/ACX720-V3-SCH.pdf`：已阅读并渲染第 1、2、3、9、10、12 页。
- `vendor/06_原理图&PCB/ACX720-V3/ACX720-V3-35_Top.png`：用于核对接口位置与电源丝印。

LED0 阴极接地，因此高电平点亮。S4 有上拉，按下接地，经电平转换器送往 FPGA。
Bank16 供电来自 VCCIO（原理图第 3 页），由第 12 页的电路和 P6 设置；
本实验使用配套引脚表的 LVCMOS33 设置，假定未改动默认 3.3 V I/O 配置。
若曾调整 P6 或 VCCIO，先核实实际电压再下载。

已创建点灯顶层、XDC、工程脚本并生成 bitstream；详见 [点灯教程](../docs/acx720_bringup.md)。
用户已于 2026-11-24 确认点灯成功；随后 UART 回环和完整 AI 推理也已通过，见 [AI 验证记录](../reports/ai_validation.md)。

## 出厂程序检查参考

按 V3 手册连接配套电源。如果出厂程序仍在：全部拨码开关拨到上方时 LED 闪烁，
全部拨到下方时 LED 常亮，S4 用于整体复位。这是手册描述，不作为本次已执行项目。
若原程序被覆盖，这些现象可能不会出现，不能仅据此判定硬件损坏。
用户已确认曾在 Vivado 中成功下载自己编译的 `.bit`，后续沿用当时连接方式。
复现时在 Hardware Manager 实际识别到器件后，再下载对应实验程序。

本实验约束为 `acx720_v3_heartbeat.xdc`，只约束点灯所需的三个端口。
UART 回环另有 `acx720_v3_uart_top.v` 与 `acx720_v3_uart.xdc`，参见 [串口教程](../docs/uart_loopback.md)。
串口实物验证已通过。完整 AI 工程使用 `acx720_v3_ai_top.v` 和 `acx720_v3_ai.xdc`，
端口保持相同，但 LED1 现在表示推理完成，详见 [AI 上板教程](../docs/ai_bringup.md)。

本次只下载到 FPGA 的易失配置 SRAM；断电即失，未修改配置 Flash。
实验按点灯、UART、分类核心的顺序完成，保留三套独立工程供学习复现。
